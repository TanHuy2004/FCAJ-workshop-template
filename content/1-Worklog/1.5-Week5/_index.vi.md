### Kết quả đạt được:

* Hiểu quy trình chuyển đổi ứng dụng từ kiến trúc Monolithic sang Microservices và Cloud-Native trên AWS.

* Xây dựng và triển khai ứng dụng Serverless sử dụng:
  * AWS Lambda
  * API Gateway
  * DynamoDB
  * Amazon S3
  * Amazon SQS
  * Amazon SNS
  * AWS Step Functions

* Xây dựng API theo mô hình RESTful và GraphQL, đồng thời triển khai ứng dụng SPA với Amazon Cognito để xác thực và phân quyền.

* Hiểu quy trình triển khai ứng dụng tự động bằng AWS SAM và AWS CodePipeline, kết hợp CI/CD và sử dụng Amazon CloudWatch, AWS X-Ray để giám sát hệ thống.

* Làm quen với các dịch vụ AI trên AWS và biết cách ứng dụng AI vào xử lý dữ liệu, tự động hóa tác vụ và nâng cao trải nghiệm người dùng.
