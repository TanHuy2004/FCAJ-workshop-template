### Week 5 Achievements:

* Understood the process of migrating applications from Monolithic architecture to Microservices and Cloud-Native architecture on AWS.

* Built Serverless applications using:
  * AWS Lambda
  * API Gateway
  * DynamoDB
  * Amazon S3
  * Amazon SQS
  * Amazon SNS
  * AWS Step Functions

* Built RESTful and GraphQL APIs and deployed a Single Page Application (SPA) with authentication and authorization using Amazon Cognito.

* Learned automated application deployment using AWS SAM and AWS CodePipeline, implemented CI/CD workflows, and monitored applications with Amazon CloudWatch and AWS X-Ray.

* Gained hands-on experience with AWS AI services and learned how to leverage AI for data processing, task automation, and enhancing user experience.
